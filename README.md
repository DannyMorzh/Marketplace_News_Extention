# Marketplace News Monitor

Браузерное расширение для Chrome для сбора и анализа изменений на маркетплейсах (Wildberries, Ozon, Яндекс Маркет) с использованием LLM (OpenRouter / DeepSeek / Gemini).

## Возможности

- Автоматический сбор новостей с трёх маркетплейсов каждые 6 часов
- Фильтрация по датам и источникам
- Умный анализ через LLM: категоризация, оценка критичности (Impact Score 1-5), рекомендации
- Генерация черновиков задач для Jira/YouTrack
- Сохранение состояния фильтров между открытиями попапа
- Цветовая индикация источников (фиолетовый — WB, голубой — Ozon, жёлтый — Яндекс)

## Интерфейс попапа

| Элемент | Действие |
|---------|----------|
| **Поле «С»** | Начало диапазона дат для фильтрации |
| **Поле «По»** | Конец диапазона дат (включая этот день) |
| **Чекбокс WB** | Включить/выключить новости Wildberries |
| **Чекбокс Ozon** | Включить/выключить новости Ozon |
| **Чекбокс Yandex** | Включить/выключить новости Яндекс Маркета |
| **«Применить фильтр»** | Загрузить новости по выбранным параметрам |
| **🗑️ (в фильтрах)** | Сбросить все фильтры: даты на сегодня, чекбоксы — выключены, список очищен |
| **🔄 (в заголовке)** | Принудительно пересобрать новости со всех источников |
| **⚙️ (в заголовке)** | Открыть настройки расширения (API-ключ, автоанализ) |
| **«🤖 Анализировать с LLM»** | Отправить отфильтрованные новости в AI для анализа |
| **«📋 Задача»** (на карточке) | Скопировать черновик задачи в буфер обмена |
| **«🔍 Подробнее»** (на карточке) | Показать полный текст новости |

## Карточка новости

Каждая новость отображается с:
- **Заголовком** и **источником** (цветной бейдж)
- **Датой** публикации
- **Типом** (Новое / Изменение / Устаревание / Удаление)
- **Критичностью** (⚠️ Критичное — если изменение требует немедленного внимания)
- **Разделами** (API, Логистика, Тарифы и т.д.)
- **Содержанием** (первые 300 символов)

После LLM-анализа добавляются:
- **Impact Score** (1-5) с цветовой индикацией (красный — 5, жёлтый — 3, серый — 1)
- **Категория** (💰 Тарифы, 🚚 Логистика, 🔌 API, ⚖️ Юридическое и т.д.)
- **Рекомендация** (💡 что делать продавцу)

## Настройки (страница ⚙️)

| Поле | Описание |
|------|----------|
| **API Key** | Ключ от OpenRouter (`sk-or-v1-...`) для доступа к LLM-моделям |
| **Автоанализ** | Включить автоматический анализ новых новостей каждые 6 часов |
| **«Сохранить»** | Сохранить API-ключ и настройки |
| **«Проверить подключение»** | Проверить, работает ли API-ключ |
| **Статистика** | Всего новостей, критических изменений, время последнего сбора и анализа |

## LLM-анализ

Используется OpenRouter API (модель Google Gemini 2.5 Flash — бесплатно).

**Возвращаемые данные:**
- `overall_summary` — общая сводка за период
- `category` — категория изменения
- `impact` — оценка влияния (1-5)
- `summary` — краткое описание
- `seller_action` — рекомендуемое действие

**Генерация задачи:**
- Название в формате `[Маркетплейс] Краткое описание`
- Описание изменения
- Критерии приёмки (3-5 пунктов)
- Приоритет (High/Medium/Low)

## Установка

1. Скачайте или клонируйте репозиторий
2. Откройте `chrome://extensions/`
3. Включите **«Режим разработчика»** (правый верхний угол)
4. Нажмите **«Загрузить распакованное расширение»**
5. Выберите папку `marketplace-news-monitor`
6. Получите API-ключ на https://openrouter.ai/keys
7. Откройте настройки расширения (⚙️) и вставьте ключ
